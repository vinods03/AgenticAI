Here, we use agents to review SQL for security issues, performance bottlenecks and to check if bext practices are being adhered to.
Apart from the specialist agents that review security issues, performance bottlenecks and best practices adherence, we have also used a handoff agent that is able to consolidate the reviews.
Also, function tools are used for saving the review report and for calculating the SQL metrics.
We have used the OpenAI agents SDK framework here.
